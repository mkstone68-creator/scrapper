Frequently Asked Questions

Everything you need to know about ScrapLink.

General
What is ScrapLink? +

ScrapLink is a professional web scraping service that converts any website into a downloadable ZIP archive. It retrieves the complete source code — HTML, CSS, JavaScript, images, fonts — and delivers it organized in a single file.

Is ScrapLink free to use? +

Yes, ScrapLink is currently free. Each IP address is limited to 10 scrapes per day to ensure fair usage for everyone. This limit resets every day at midnight UTC.

Is my data stored on your servers? +

No. Scraped files are temporarily stored for up to 2 hours to allow you to download them, then automatically and permanently deleted. We never analyze, index, or retain your scraped content.

Scraping
What's the difference between Fast mode and Full mode? +

Fast mode (Axios + Cheerio) fetches raw HTML responses without executing JavaScript. It is ideal for static websites, WordPress, and simple SSR sites. It is very fast and works in seconds.

Full mode (Playwright) launches a headless Chromium browser, executes all JavaScript, and scrapes the fully rendered page. It is required for React, Next.js, Vue, Angular, and any site that builds its content client-side.

Does it work with React / Next.js / Vue apps? +

Yes. Use Full (Playwright) mode. It runs a real headless browser that fully executes JavaScript before scraping, capturing the hydrated HTML and all dynamically loaded assets.

What files are included in the ZIP? +

The ZIP contains everything retrieved from the target site:

  • HTML pages (.html)
  • CSS stylesheets (.css)
  • JavaScript files (.js)
  • Images (.png, .jpg, .svg, .webp…)
  • Web fonts (.woff2, .ttf…)
  • Next.js static assets (_next/static/) when applicable
Why is my ZIP empty or incomplete? +

This usually happens when:

  • The site uses advanced bot detection (Cloudflare, CAPTCHA)
  • Content is loaded via authenticated APIs
  • You used Fast mode on a JavaScript-heavy site — try Full (Playwright) mode instead
Limits & Policy
How many scrapes can I do per day? +

Each IP address is limited to 10 scrapes per day. The counter resets every day at midnight UTC. This limit is enforced server-side and cannot be bypassed client-side.

Which sites are blocked from scraping? +

The domain xhrishoost.site is permanently blocked as it belongs to the service owner. Beyond this, please respect the robots.txt and terms of service of any site you scrape. Using ScrapLink for unauthorized data extraction may violate applicable laws.

How long is my download link valid? +

ZIP files are available for download for 2 hours after generation. After that, they are automatically deleted from our servers. Make sure to download your file before the link expires.
