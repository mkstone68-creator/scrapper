📖 Introduction

ScrapLink is a web scraping service that lets you download the complete source code of any website as an organized ZIP archive — no coding required.

It supports two scraping engines: a lightweight HTTP client for static sites, and a full headless browser for JavaScript-rendered applications.

💡
ScrapLink is intended for legitimate use cases such as offline archiving, development reference, and design inspiration. Always respect the target site's robots.txt and terms of service.

🚀 Getting Started

Scraping a website with ScrapLink takes less than a minute.

1

Go to the homepage and paste the full URL of the site you want to scrape (e.g. https://example.com).

2

Click Scrape site or press Enter. ScrapLink will start analysing the target site immediately.

3

Watch the real-time log terminal as pages and assets are retrieved. A progress bar shows the overall completion.

4

Once complete, click Download ZIP. Your file is available for 2 hours, then auto-deleted.

⚙️ Scraping Modes

ScrapLink offers two engines. Choosing the right one is important for getting complete results.

Feature Fast Mode Full Mode
Engine Axios + Cheerio Playwright (Chromium)
Speed Very fast (seconds) Slower (browser startup)
JavaScript execution No Yes (full render)
Best for Static sites, WordPress, simple SSR React, Next.js, Vue, Angular, SPAs

⚡ Fast Mode

Fast mode uses Axios to make HTTP requests and Cheerio (a server-side jQuery) to parse the HTML and discover linked assets.

When to use it

  • Static HTML websites
  • WordPress, Joomla, and classic CMS sites
  • Server-side rendered pages (PHP, Ruby on Rails, Django)
  • Documentation sites (GitBook, MkDocs, Docusaurus static export)

Limitations

  • Does not execute JavaScript — content rendered client-side will be missing
  • Cannot handle login-gated or AJAX-loaded content
✅
If the target site looks the same with JavaScript disabled in your browser, Fast mode will work perfectly.

🎭 Full Mode (Playwright)

Full mode launches a headless Chromium browser via Playwright. It navigates to each page, waits for the JavaScript to fully execute, then captures the rendered HTML and all loaded assets.

When to use it

  • React, Next.js, Vue, Angular, Svelte applications
  • Single Page Applications (SPAs)
  • Sites that load content via client-side API calls
  • Any site where Fast mode returns empty or incomplete content

Limitations

  • Slower than Fast mode due to browser startup overhead
  • May be blocked by advanced bot detection (Cloudflare, hCaptcha)
  • Cannot access content behind authentication
⚠️
Full mode uses significantly more server resources. Please use it only when needed, and be patient while the browser completes rendering.

📦 ZIP Output Structure

The downloaded ZIP is organized to mirror the original site's asset structure. Here is a typical example:

website.zip
 ├── index.html
 ├── about.html
 ├── contact.html
 ├── css/
 │   ├── main.css
 │   └── fonts.css
 ├── js/
 │   ├── app.js
 │   └── vendor.js
 ├── images/
 │   ├── hero.webp
 │   └── logo.svg
 ├── fonts/
 │   └── inter.woff2
 └── _next/static/  ← Next.js only

Paths are rewritten so HTML files reference local assets — you can open index.html directly in a browser for most static sites.

⏱
ZIP files are stored on our servers for 2 hours after creation, then permanently deleted. Download your file promptly.

📊 Rate Limits

To ensure a fair and stable service for everyone, ScrapLink enforces the following limit:

  • 10 scrapes per day per IP address
  • The counter resets every day at midnight UTC
  • The limit is applied server-side and cannot be bypassed
⚠️
If you hit the daily limit, you will receive a clear error message. Simply try again tomorrow after midnight UTC.

🚫 Blocked Domains

Certain domains are permanently blocked and cannot be scraped through ScrapLink. Any URL containing the keyword xhrishost (including xhrishost.site) is blocked — these domains belong to the service owner.

Attempting to scrape a blocked domain will result in an immediate error, both on the client and server side.

🚫
Beyond the explicit blocklist, you are responsible for ensuring that your use of ScrapLink complies with the target site's robots.txt, terms of service, and applicable laws (GDPR, CFAA, etc.).

💡 Tips & Tricks

Choose the right mode

Start with Fast mode. If the result is empty or missing content, switch to Full mode. Full mode is always more complete but takes longer.

Next.js and React apps

Always use Full (Playwright) mode for Next.js, React, Vue, or any SPA. Fast mode will only capture the empty shell HTML without any rendered content.

Large sites

For large sites with hundreds of pages, the scrape may take several minutes. Watch the terminal log to track which pages are being processed. The progress bar shows real-time completion.

Open your ZIP locally

Unzip the archive and open index.html in your browser. For sites that use absolute paths or require a server, use a local server like npx serve . inside the unzipped folder.
